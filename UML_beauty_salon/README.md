# ✂️ Проектирование Информационной Системы «Парикмахерская»

Проект включает в себя полное проектирование логической архитектуры, ролевой модели и анализ процессов для системы управления салоном красоты.

## 📌 Основные результаты
* **Моделирование ролей (Use Case Diagram):** Проработаны сценарии использования для 4 акторов (*Клиент, Администратор, Менеджер, Бухгалтер*) с применением связей `<<include>>`, `<<extend>>` и `Generalization`.
* **Логическая модель (Class Diagram):** Построена диаграмма классов системы (сущности `Person`, `Employee`, `Client`, `Master`, `Service`, `Appointment`, `PaymentReceipt`) с учетом связей ООП и атрибутов.
* **Анализ методологий:** Проведено сравнение гибких методологий (*Scrum, Kanban, XP*) и обоснован выбор **Scrum** для реализации системы.

## 🛠 Технический стек и инструменты
`UML` `Use Case Diagram` `Class Diagram` `Visual Paradigm` `Agile / Scrum`
