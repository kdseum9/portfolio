# 🗄️ Цикл лабораторных работ по базам данных (PostgreSQL)

**Стек технологий:** `PostgreSQL`, `ER-диаграммы`, `SQL (DDL, DML, DQL)`

---

## 📌 Описание проекта
Комплекс из 4 лабораторных работ, выполненных в рамках изучения дисциплины "Базы данных". Проект охватывает полный жизненный цикл работы с реляционными СУБД — от концептуального проектирования до написания сложных запросов и триггеров.

---

## 🚀 Структура лабораторных работ

### **Лабораторная работа №1. Концептуальное и логическое проектирование**
* Разработка инфологической (ER) и даталогической моделей предметной области.
* Определение сущностей, первичных (`PK`) и внешних (`FK`) ключей, типов связей (*1:N*, *N:M*).

### **Лабораторная работа №2. Физическая реализация и развертывание на сервере**
* Написание DDL-скриптов создания таблиц с ограничениями целостности (`CHECK`, `NOT NULL`, `UNIQUE`, `FOREIGN KEY`).
* Подготовка DML-скриптов для наполнения таблиц тестовыми данными.


### **Лабораторная работа №3. Сложные SQL-запросы и аналитика (DQL)**
* Реализация многотабличных выборок с использованием различных видов соединений (`INNER JOIN`, `LEFT/RIGHT JOIN`).
* Применение агрегатных функций (`COUNT`, `SUM`, `AVG`) и группировок с условиями фильтрации (`GROUP BY`, `HAVING`).
* Написание вложенных и коррелированных подзапросов для комплексной фильтрации данных.
*  Нормализация таблиц до **3-й нормальной формы (3NF)** для устранения избыточности и аномалий.

### **Лабораторная работа №4. Программирование СУБД на PL/pgSQL**
* Разработка хранимой функции и триггера для автоматической обработки данных на стороне СУБД.
